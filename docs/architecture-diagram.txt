- Cloudflare Worker is used as a webhook proxy.
- Worker helps avoid direct Google Apps Script webhook timeout and redirect issues.
- LINE events are written into LINE_INBOX_QUEUE first.
- Queue Worker processes messages asynchronously.
- Delivery results are stored in LINE_DELIVERY_LOG.
